# Google Calendar для справжніх задач

Погоджено користувачем: односторонньо бот → Google. Додавання, редагування, скасування й підтвердження залишаються в боті; події Google не впливають на зобов’язання.

Підхід: зберегти OAuth і підключений календар, відокремити основний синхронізатор та його ідентифікатори подій від лабораторних записів. Не перейменовувати API redirect URI й не вимагати нового доступу з ширшими scopes. Google Cloud Testing поки обмежує аудиторію власником.

- [x] Написати тести перенесення справжніх задач, виконання, скасування та ізоляції власників.
- [x] Додати режим main до підключення, таблицю відповідностей та GoogleCalendar-сервіс; перевірити тести.
- [x] Змінити «Мої календарі»: Google/Android та iPhone; приховати керування старим ICS-посиланням і головну тестову кнопку.
- [x] Оновити сторінку OAuth для основного режиму, планувальник і видалення особистих даних.
- [x] Резервна копія, встановлення, переведення власного підключення у main, жива перевірка події й статусу, GitHub.
