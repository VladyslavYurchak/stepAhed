# Вечірній підсумок

Користувач погодив додати підсумок перед сном. Рішення реалізації: за 30 хвилин до збереженого часу сну, у місцевому часовому поясі, з вимкненням у налаштуваннях. Без зміни задач, штрафів чи дедлайнів.

- [x] Відтворити час запуску, підрахунок власних задач, ніч після опівночі, вимкнення й прострочену доставку тестами.
- [x] Додати налаштування та маркер дня у профіль, окремий сервіс підсумку й виклик у чинному планувальнику.
- [x] Відкидати доставку після початку сну або зміни налаштувань, залишити дійсні повторні спроби до сну.
- [x] Перевірити в ізольованому середовищі, встановити з резервною копією та зберегти в GitHub.

Для запуску тестів використовується приватна ізольована копія коду на Hostinger, бо Windows Application Control блокує локальний PHP. Копія не містить production .env; база — SQLite у пам’яті, APP_KEY тимчасовий.
