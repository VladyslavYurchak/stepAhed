# Project instructions

This is Крок вперед, a separate Telegram bot. Never modify the school application or reuse its database, secrets, or public directory.

Read docs/CONCEPT.md before changing product rules. Distinguish approved rules from proposals. Voluntary direct donations to administrator-approved charitable jars and manual receipt moderation are approved. Never collect payments into the service, gate bot access on donations, or enable commercial billing without further agreement.

Use PHP/Laravel. Keep credentials out of Git and logs. Run vendor/bin/phpunit for deadline, ownership, moderation, recurrence and setup changes. All scheduling is stored in UTC with the schedule timezone fixed at creation.
